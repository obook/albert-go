# MR 3 : kiosque - plan d'implémentation

> **Pour l'agent qui exécute :** sous-skill requis, superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans. Étapes en cases à cocher (`- [ ]`).

**But :** avec `--kiosque` (ou `kiosque=oui`), le serveur d'Albert Go ouvre des sessions de classe : l'enseignant saisit sa clé sur `/kiosque`, les élèves rejoignent par un lien et un code à 4 chiffres, sans voir la clé.

**Architecture :** le module `serveur/kiosque.py` reprend les sessions et les cookies signés de l'atelier (`web/handler_kiosque.py`), sans les niveaux "autonome / encadré". `serveur/serveur.py` garde l'accès à la page et à `/v1`, relaie avec la clé de la session et sert un script `/serveur.js` qui donne à la page les adresses réseau et la session (la CSP d'Albert Go interdit les scripts en ligne). Côté page, `public/kiosque.html` est la connexion au style d'Albert Go, `public/js/kiosque.js` branche le kiosque autour de l'interface sans toucher à Discussion ni à Imprimerie.

**Technique :** Python 3.10+, httpx, pytest ; JavaScript du navigateur, tests `node --test`.

**Spec :** `docs/specs/2026-10-15-fusion-atelier.md` (section Kiosque). MR 1 fusionnée dans `main`.

## Contraintes globales

- Une seule session à la fois ; durées 1 h, 2 h, 3 h, journée (8 h) ; 2 h par défaut.
- Mode unique : pas de choix "Mode de travail" ; les réglages du prof sont les valeurs de départ des élèves.
- Le jeton et le code de la session ne sont servis qu'à l'enseignant (rôle signé dans le cookie).
- Sans session valide : la page `/` renvoie vers `/kiosque`, `/v1/...` répond 401 `{"detail": ..., "kiosque": "terminee"}`.
- Élèves et prof en kiosque : mode partagé forcé (données dans l'onglet).
- Textes en FR, EN, ES, DE ; même jeu de clés dans les quatre fichiers (`tests/i18n.test.js`).
- Français correctement accentué, ponctuation ASCII seulement.
- Aucun nouveau paquet Python ; le QR code reste calculé dans le navigateur (`vendor/qrcode-generator`) : pas de route `/api/qrcode`.

## Points à surveiller en revue

1. Cookie d'une session précédente (prof qui rouvre une session) : il ne vaut plus rien. Test : Tâche 1, `test_cookie_d_une_ancienne_session_refuse`.
2. Élève qui modifie son cookie pour se dire enseignant : refusé. Test : Tâche 1, `test_role_falsifie_refuse`.
3. Enseignant qui ouvre le lien élève dans son navigateur et tape le code : il reste enseignant. Test : Tâche 2, `test_prof_qui_tape_le_code_reste_prof`.
4. Session expirée pendant le cours : `/v1` répond 401 et la page le dit. Test : Tâche 2, `test_v1_sans_session_401`.
5. Réglages du prof forgés (température 1e309, liste de 1000 moteurs, modèle de 10 Ko) : bornés ou ignorés. Test : Tâche 1, `test_reglages_bornes`.

```python
"""Mode kiosque : l'enseignant ouvre une session de classe avec sa clé API.

Les élèves rejoignent la session par un lien (QR code) et un code à
4 chiffres, sans voir la clé. Une seule session à la fois. Le rôle
(enseignant ou élève) est signé dans le cookie : un élève ne peut pas
se déclarer enseignant.

Projet : Albert Go, https://forge.apps.education.fr/booklageolivier/albert-go
Repris de L'Atelier d'Albert (Romain P., Luce P.B., Théossian S.D., O. Booklage)
Licence : GPL-3.0-or-later
"""

import hashlib
import hmac
import math
import re
import secrets
import threading
import time
from http.cookies import SimpleCookie

import httpx

from serveur import config, proxy

COOKIE = "kiosque-session"
DUREES = {"1h": 3600, "2h": 7200, "3h": 10800, "journee": 28800}
ROLES = {"enseignant", "eleve"}
OUTILS = ("recherche", "calcul", "tirage", "calendrier", "compteur")

_session = None
_verrou = threading.Lock()
# Secret tiré au lancement : les cookies ne survivent pas à un redémarrage.
_secret = secrets.token_bytes(32)


def _signature(token, role):
    return hmac.new(_secret, f"{token}|{role}".encode(), hashlib.sha256).hexdigest()


def _courante():
    """Session en cours, ou None ; une session expirée est effacée. Sous verrou."""
    global _session
    if _session is not None and time.time() > _session["expiration"]:
        _session = None
    return _session


def creer_session(cle_api, duree_code):
    """Ouvre une session (remplace la précédente) ; renvoie (jeton, code à 4 chiffres)."""
    global _session
    with _verrou:
        _session = {
            "token": secrets.token_urlsafe(24),
            "code": f"{secrets.randbelow(10000):04d}",
            "cle_api": cle_api,
            "expiration": time.time() + DUREES.get(duree_code, DUREES["2h"]),
            "reglages": None,
        }
        return _session["token"], _session["code"]


def terminer_session():
    global _session
    with _verrou:
        _session = None


def session_active():
    with _verrou:
        return _courante() is not None


def temps_restant():
    with _verrou:
        session = _courante()
        return max(0, int(session["expiration"] - time.time())) if session else 0


def cle_api():
    with _verrou:
        session = _courante()
        return session["cle_api"] if session else None


def infos_enseignant():
    """Jeton et code de la session : réservés à la page de l'enseignant."""
    with _verrou:
        session = _courante()
        return {"token": session["token"], "code": session["code"]} if session else None


def verifier_code(token, code):
    """Jeton et code de la session, comparés en temps constant."""
    if not (token.isascii() and code.isascii()):
        return False
    with _verrou:
        session = _courante()
        if session is None:
            return False
        return hmac.compare_digest(session["token"], token) and hmac.compare_digest(session["code"], code)


def cookie(role):
    """Valeur signée "<jeton>.<rôle>.<signature>" ; rôle inconnu : élève."""
    role = role if role in ROLES else "eleve"
    with _verrou:
        session = _courante()
        if session is None:
            return None
        token = session["token"]
    return f"{token}.{role}.{_signature(token, role)}"


def role_du_cookie(valeur):
    """Rôle signé dans le cookie, ou None : signature fausse, autre session, session expirée."""
    morceaux = (valeur or "").split(".")
    if len(morceaux) != 3:
        return None
    token, role, signature = morceaux
    # isascii : compare_digest lève TypeError sur une chaîne non ASCII.
    if role not in ROLES or not (token.isascii() and signature.isascii()):
        return None
    if not hmac.compare_digest(signature, _signature(token, role)):
        return None
    with _verrou:
        session = _courante()
        if session is None or not hmac.compare_digest(session["token"], token):
            return None
    return role


def valeur_cookie(handler):
    """Valeur du cookie de session envoyé par le navigateur, ou None."""
    cookies = SimpleCookie()
    try:
        cookies.load(handler.headers.get("Cookie", ""))
    except Exception:
        return None
    morceau = cookies.get(COOKIE)
    return morceau.value if morceau else None


def role_de_la_requete(handler):
    return role_du_cookie(valeur_cookie(handler))


def enregistrer_reglages(reglages):
    """Range les réglages du prof ; l'heure d'expiration sert d'identifiant de session."""
    with _verrou:
        session = _courante()
        if session is None:
            return False
        session["reglages"] = dict(reglages, session=int(session["expiration"]))
        return True


def reglages():
    with _verrou:
        session = _courante()
        return session["reglages"] if session else None


def _nombre(valeur):
    """Nombre fini, ni booléen ni texte ; None sinon."""
    if isinstance(valeur, bool) or not isinstance(valeur, (int, float)) or not math.isfinite(valeur):
        return None
    return valeur


def valider_reglages(corps):
    """Garde les réglages connus, avec des valeurs sûres : tout le reste est ignoré."""
    propres = {}
    modele = corps.get("modele")
    if isinstance(modele, str) and re.fullmatch(r"[\w.:/-]{1,100}", modele):
        propres["modele"] = modele
    bornes = {"temperature": (0, 2), "topK": (1, 50), "echanges": (0, 11)}
    for nom, (minimum, maximum) in bornes.items():
        valeur = _nombre(corps.get(nom))
        if valeur is not None:
            valeur = min(maximum, max(minimum, valeur))
            propres[nom] = valeur if nom == "temperature" else int(valeur)
    for nom in OUTILS:
        if isinstance(corps.get(nom), bool):
            propres[nom] = corps[nom]
    moteurs = corps.get("fournisseurs")
    if isinstance(moteurs, list):
        propres["fournisseurs"] = [m for m in moteurs if isinstance(m, str) and re.fullmatch(r"[a-z-]{1,30}", m)][:3]
    return propres


def cle_acceptee(cle):
    """La clé ouvre-t-elle la liste des modèles d'Albert ?"""
    api_base = config.load_config()["api_base"].rstrip("/")
    try:
        with proxy.creer_client_http(httpx.Timeout(10.0)) as http:
            reponse = http.get(api_base + "/v1/models", headers={"Authorization": f"Bearer {cle}"})
    except httpx.HTTPError:
        return False
    return reponse.status_code == 200
```

    def _session_terminee(self):
        relais.repondre_json(self, 401, {"detail": "Session de classe terminée.", "kiosque": "terminee"})

    def _rediriger(self, adresse, cookie=None):
        self.send_response(302)
        self.send_header("Location", adresse)
        if cookie is not None:
            self.send_header("Set-Cookie", cookie)
        self.end_headers()

    def _porte_kiosque(self, chemin):
        """En kiosque, sans session valide : 302 vers /kiosque (page) ou 401 (/v1). True si la requête passe."""
        if not self.server.kiosque or (chemin not in PAGES_PROTEGEES and not chemin.startswith("/v1/")):
            return True
        if kiosque.role_de_la_requete(self):
            return True
        if chemin.startswith("/v1/"):
            self._session_terminee()
        else:
            self._rediriger("/kiosque")
        return False

    def _formulaire(self):
        """Champs d'un formulaire POST (4 Ko au plus), ou None après avoir répondu 400."""
        try:
            taille = int(self.headers.get("Content-Length") or 0)
        except ValueError:
            taille = -1
        if not 0 <= taille <= FORMULAIRE_MAX:
            relais.repondre_json(self, 400, {"detail": "Formulaire invalide."})
            self.close_connection = True
            return None
        texte = self.rfile.read(taille).decode("utf-8", "replace")
        return {nom: valeurs[0] for nom, valeurs in parse_qs(texte).items()}

    def _kiosque_post(self):
        champs = self._formulaire()
        if champs is None:
            return
        action = champs.get("action", "")
        role = kiosque.role_de_la_requete(self)
        if action == "login":
            cle = champs.get("cle_api", "").strip()[:500]
            if not cle:
                self._rediriger("/kiosque?erreur=cle-requise")
            elif not kiosque.cle_acceptee(cle):
                self._rediriger("/kiosque?erreur=cle-refusee")
            else:
                kiosque.creer_session(cle, champs.get("duree", "2h"))
                self._rediriger("/", f"{kiosque.COOKIE}={kiosque.cookie('enseignant')}; Path=/; HttpOnly; SameSite=Lax")
        elif action == "code":
            token, code = champs.get("token", "").strip(), champs.get("code", "").strip()
            if not kiosque.session_active():
                self._rediriger("/kiosque?erreur=aucune-session")
            elif not kiosque.verifier_code(token, code):
                self._rediriger("/kiosque?" + urlencode({"erreur": "code", "token": token}))
            elif role == "enseignant":
                # Le prof qui essaie le lien élève dans son navigateur reste prof.
                self._rediriger("/")
            else:
                self._rediriger("/", f"{kiosque.COOKIE}={kiosque.cookie('eleve')}; Path=/; HttpOnly; SameSite=Lax")
        elif action == "logout":
            # Seul le prof (rôle signé) ferme la session de la classe.
            if role == "enseignant":
                kiosque.terminer_session()
            efface = None
            if kiosque.valeur_cookie(self) is not None:
                efface = f"{kiosque.COOKIE}=; Path=/; HttpOnly; SameSite=Lax; Max-Age=0"
            self._rediriger("/kiosque", efface)
        else:
            self._rediriger("/kiosque?erreur=action")

    def _reglages_prof(self):
        if kiosque.role_de_la_requete(self) != "enseignant":
            relais.repondre_json(self, 403, {"detail": "Réservé à l'enseignant."})
            return
        try:
            taille = int(self.headers.get("Content-Length") or 0)
            corps = json.loads(self.rfile.read(taille)) if 0 < taille <= FORMULAIRE_MAX else None
        except ValueError:
            corps = None
        if not isinstance(corps, dict):
            relais.repondre_json(self, 400, {"detail": "Réglages invalides."})
            return
        kiosque.enregistrer_reglages(kiosque.valider_reglages(corps))
        relais.repondre_json(self, 200, {"ok": True})

    def _serveur_js(self):
        """Adresses réseau et session de cette page ; la CSP interdit les scripts en ligne."""
        port = self.server.server_address[1]
        protocole = "https" if self.server.ssl else "http"
        session = None
        role = kiosque.role_de_la_requete(self) if self.server.kiosque else None
        if role == "enseignant":
            session = dict(kiosque.infos_enseignant() or {}, role=role)
        elif role == "eleve":
            session = {"role": role, "reglages": kiosque.reglages()}
        donnees = {"adresses": [f"{protocole}://{ip}:{port}" for ip in self.server.adresses], "kiosque": session}
        texte = "var SERVEUR = " + json.dumps(donnees, ensure_ascii=False).replace("</", "<\\/") + ";\n"
        contenu = texte.encode("utf-8")
        self.send_response(200)
        self.send_header("Content-Type", "application/javascript; charset=utf-8")
        self.send_header("Content-Length", str(len(contenu)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        self.wfile.write(contenu)

```javascript
/*
 * kiosque.js
 * Le kiosque autour de l'interface : mode partagé forcé, réglages du prof
 * comme valeurs de départ des élèves, bandeau et déconnexion, retour à
 * /kiosque quand la session se termine. Rien à faire hors kiosque.
 *
 * SERVEUR vient de /serveur.js (serveur/serveur.py) : adresses réseau et
 * session de cette page. Absent hors serveur (tests).
 *
 * Projet : Albert Go, https://forge.apps.education.fr/booklageolivier/albert-go
 * Repris de L'Atelier d'Albert (kiosque-garde.js, kiosque-niveau.js)
 * Licence : GPL-3.0-or-later
 */
'use strict';

/** Adresses réseau et session de cette page. */
const Serveur = typeof SERVEUR !== 'undefined' ? SERVEUR : { adresses: [], kiosque: null };
const Kiosque = Serveur.kiosque;

/** Réglages que le prof donne à ses élèves comme valeurs de départ. */
const REGLAGES_PARTAGES = ['modele', 'temperature', 'topK', 'echanges', 'recherche', 'calcul', 'tirage', 'calendrier', 'compteur', 'fournisseurs'];

/** Nom d'enregistrement quand il diffère du nom dans reglages (reglages.js). */
const NOMS_STOCKES = { topK: 'top-k' };

/** Sondage de la session, en millisecondes. */
const SONDAGE_KIOSQUE_MS = 20000;

/**
 * Réglages du prof à envoyer au serveur.
 *
 * @param {Object} r - Réglages de la page (stockage.js).
 * @returns {Object} Les seuls réglages partagés.
 */
function reglagesProf(r) {
    return Object.fromEntries(REGLAGES_PARTAGES.map(nom => [nom, r[nom]]));
}

/**
 * Réglages du prof à recopier chez l'élève.
 *
 * @param {Object} prof - Réglages reçus du serveur.
 * @param {string[]} moteursConnus - Moteurs de recherche de cette page.
 * @returns {Array<Array>} Paires [nom dans reglages, valeur].
 */
function reglagesAppliques(prof, moteursConnus) {
    return REGLAGES_PARTAGES.filter(nom => nom in prof).map(nom => [nom,
        nom === 'fournisseurs' ? prof[nom].filter(m => moteursConnus.includes(m)) : prof[nom]]);
}

/**
 * Valeur telle que stockage.js l'enregistre.
 *
 * @param {*} valeur - Booléen, liste ou nombre.
 * @returns {string} Texte enregistré.
 */
function valeurStockee(valeur) {
    if (typeof valeur === 'boolean') {
        return valeur ? 'oui' : 'non';
    }
    return Array.isArray(valeur) ? valeur.join(',') : String(valeur);
}

/* Sauté sous Node, où le fichier n'est chargé que pour ses tests. */
if (typeof document !== 'undefined' && Kiosque) {
    /* Poste partagé : conversations et bibliothèque restent dans l'onglet. */
    if (!partage) {
        changerPartage(true);
    }
    $('partage-reglage').closest('fieldset').hidden = true;

    if (Kiosque.role === 'eleve' && Kiosque.reglages) {
        /* Une fois par session : l'élève peut ensuite changer ses réglages. */
        let deja = null;
        try {
            deja = sessionStorage.getItem('albert-go.kiosque-reglages');
        } catch (err) {
            /* Stockage bloqué : les réglages du prof sont repris à chaque chargement. */
        }
        if (deja !== String(Kiosque.reglages.session)) {
            for (const [nom, valeur] of reglagesAppliques(Kiosque.reglages, Object.keys(Recherche.MOTEURS))) {
                reglages[nom] = valeur;
                ecrire(NOMS_STOCKES[nom] || nom, valeurStockee(valeur));
            }
            try {
                sessionStorage.setItem('albert-go.kiosque-reglages', String(Kiosque.reglages.session));
            } catch (err) {
                /* Stockage bloqué. */
            }
        }
    }

    if (Kiosque.role === 'enseignant') {
        const envoyer = () => fetch('/api/kiosque-reglages', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(reglagesProf(reglages))
        }).catch(() => {});
        envoyer();
        $('reglages').addEventListener('close', envoyer);

        const bandeau = document.createElement('p');
        bandeau.className = 'bandeau-kiosque';
        const partager = document.createElement('button');
        partager.type = 'button';
        partager.className = 'bouton-texte outline';
        partager.textContent = t('menu.partager');
        partager.addEventListener('click', () => ouvrirPartage());
        bandeau.append(t('kiosque.bandeau', { code: Kiosque.code }), partager);
        document.querySelector('.entete').after(bandeau);
    }

    $('deconnexion-kiosque').hidden = false;
    $('deconnexion-kiosque').addEventListener('click', () => {
        const formulaire = document.createElement('form');
        formulaire.method = 'post';
        formulaire.action = '/kiosque';
        const action = document.createElement('input');
        action.type = 'hidden';
        action.name = 'action';
        action.value = 'logout';
        formulaire.append(action);
        document.body.append(formulaire);
        formulaire.submit();
    });

    setInterval(() => {
        fetch('/api/kiosque-status').then(r => r.json()).then((statut) => {
            if (!statut.active) {
                location.href = '/kiosque';
            }
        }).catch(() => {
            /* Coupure réseau ponctuelle : on réessaie au tour suivant. */
        });
    }, SONDAGE_KIOSQUE_MS);
}

/* Export pour les tests Node ; ignoré dans le navigateur. */
if (typeof module !== 'undefined') {
    module.exports = { reglagesProf, reglagesAppliques, valeurStockee };
}
```
